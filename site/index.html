Daily Persona · Plugin directory support

One deterministic review lens per day.

Daily Persona resolves one persona from a versioned, Ed25519-signed catalog. Hosts freeze that result for a conversation and use it only to influence tone and review emphasis.

The MCP server is read-only. It does not accept account data, credentials, files, or arbitrary persona URLs. Persona text is always untrusted data.

Tools

  • get_today_persona: resolve today's persona once.
  • resolve_for_date: reproduce an explicit date.
  • list_catalog: inspect bounded catalog metadata.
